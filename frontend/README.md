# ADW Frontend

SPA de Automotive Diagnostic Workbench. React + TypeScript (strict) + Vite +
Tailwind CSS 4 + React Router + TanStack Query.

## Desarrollo

```bash
npm install
npm run dev
```

Servidor de desarrollo en http://localhost:5173 con proxy `/api` hacia el
backend (http://localhost:8080).

## Scripts

- `npm run dev` — servidor de desarrollo
- `npm run build` — typecheck + build de producción
- `npm run lint` — oxlint
- `npm run preview` — previsualizar el build
